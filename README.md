
# IMDb Movie Analytics Dashboard

## Project Description
An interactive movie analytics dashboard developed using Python, Pandas and Streamlit.

## Features
- Dataset loading and exploration
- KPI metrics
- Movie genre analysis
- IMDb rating distribution
- Rating vs votes analysis
- Top 10 movies by worldwide gross
- Interactive movie filters
- Movie search using session state and forms

## Technologies Used
- Python
- Pandas
- Streamlit

## Dataset
Top 250 Movies on IMDb in 2026.

## How to Run
1. Install required libraries:
   pip install streamlit pandas

2. Run the application:
   streamlit run app.py
